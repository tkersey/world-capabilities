# Non-Goals

Foundry v0 does not add:

- OpenAI, Anthropic, GitHub, Slack, Gmail, or browser automation packages
- real cloud secret manager
- real external database
- npm runtime dependencies
- package registry
- signing or encryption
- production live smoke
- arbitrary shell capability
- new Boundary APIs
- new World APIs
- changes to world-host PR #5

No live endpoints, live credentials, vendor SDKs, exactly-once claim, or
cryptographic trust claim are present in Foundry v0.
